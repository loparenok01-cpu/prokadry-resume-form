# Промышленная эксплуатация «ПроКадры»

Чек-лист и конфигурация контура за пределами localhost.
Доработка кода от 16.10.2026 (закрыты строки 13–15 аудита + TLS/CI/заголовки).

## Что уже в коде

| мера | как включить | проверка |
|---|---|---|
| Security-заголовки (helmet) | всегда: `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `Referrer-Policy`, COOP/CORP; `X-Powered-By` убран | `curl -I http://127.0.0.1:3000/` |
| Строгий CSP | все маршруты, кроме `/presentation` (инлайн-байткод презентации) | заголовок `Content-Security-Policy` на `/` есть, на `/presentation` — нет |
| HSTS | только при защищённом соединении: нативный TLS или `X-Forwarded-Proto: https` от reverse-proxy | `curl -I -H "X-Forwarded-Proto: https" http://127.0.0.1:3000/api/health` → `Strict-Transport-Security` |
| Cap длины поиска | `?q=` длиннее 200 символов → `400` | `curl "…/api/candidates?q=<301 символ>"` → 400 |
| CI | `.github/workflows/ci.yml`: `npm ci` → `node --check` → `npm test` на каждый push/PR; требуется push репозитория на GitHub | зелёный прогон workflow |
| Опциональный нативный TLS | `TLS_CERT_FILE` + `TLS_KEY_FILE` в `.env` (PEM) — приложение само поднимается по https | в строке запуска `tls=on` |
| Честный бейдж режима | при ошибке списка ≠2xx клиент переключается на localStorage и предупреждает об этом | сценарий в `save-error-test` (фаза 3) |
| Эвристика — отдельный модуль | `public/js/heuristics.js`: работает в браузере и подключается тестами через `require()` (без `eval`) | `npm test` |

## TLS на публичном контуре

### Вариант A — reverse-proxy (рекомендуется): Caddy

Caddy сам получает и продлевает сертификат Let's Encrypt:

```
# Caddyfile
kadry.example.ru {
    reverse_proxy 127.0.0.1:3000
}
```

`src/server.js` продолжает слушать `127.0.0.1:3000` (`HOST` не менять);
Caddy ставит `X-Forwarded-Proto: https` → приложение включает HSTS.

Тот же принцип для nginx: `proxy_set_header X-Forwarded-Proto $scheme;`.

### Вариант B — нативный TLS приложения

PEM-сертификат и ключ (корпоративный CA или самоподписанный для стенда):

```
TLS_CERT_FILE=certs/server.crt
TLS_KEY_FILE=certs/server.key
```

Файлы не найдены → предупреждение в логе и запуск по http.

## Чек-лист перед публичным контуром

1. `.env`: `APP_TOKEN` — длинный случайный секрет; `HOST=127.0.0.1` (за proxy).
2. TLS: Caddy/nginx перед приложением (вариант A) или `TLS_*` (вариант B).
3. CI: репозиторий на GitHub, workflow `.github/workflows/ci.yml` зелёный.
4. Бэкап `candidates.json` (ПДн) и ограничение доступа к машине.
5. Юридическая оценка 152-ФЗ — на владельце: правовое основание обработки,
   согласие субъекта, сроки хранения и удаление резюме по требованию.
6. Нагрузочный тест и внешний пентест — по необходимости (не автоматизированы).
