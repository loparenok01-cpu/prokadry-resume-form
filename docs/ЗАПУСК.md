# Запуск проекта

Форма приёма резюме кадрового агентства «ПроКадры»: эвристика + GigaChat API.

> Команды запуска/остановки, проверка статуса, база, решения проблем — в
> [КОМАНДЫ_СЕРВЕР.md](КОМАНДЫ_СЕРВЕР.md).

## Вариант 1 — обычный (без ИИ)

Откройте `public/index.html` двойным щелчком. Работает эвристика
(извлечение полей по ключевым словам), всё сохраняется в `localStorage`.

## Вариант 2 — с сервером и GigaChat (рекомендуется)

```bash
npm install     # однократно
npm start       # http://localhost:3000
```

Откройте http://localhost:3000 — при отправке резюме текст уходит на
`POST /api/extract`, сервер вызывает GigaChat и возвращает структурированные
данные. Если сервер не запущен или ИИ недоступен, страница автоматически
использует эвристику.

### Настройка

Ключ хранится **только в `.env` на сервере** — в браузер не попадает.

1. Скопируйте `.env.example` в `.env` (или заполните существующий).
2. Впишите `GIGACHAT_AUTH_KEY` (личный кабинет Studio → проект GigaChat API
   → Настройки API → Получить ключ). Значение не коммитится: `.env`
   в `.gitignore`.
3. Параметры по умолчанию: `GIGACHAT_SCOPE=GIGACHAT_API_PERS`,
   `GIGACHAT_MODEL=GigaChat-2-Pro`, `PORT=3000`, `HOST=127.0.0.1`
   (сервер слушает только локальную машину; для доступа из сети задайте
   `HOST=0.0.0.0` в `.env` — только вместе с reverse-proxy и TLS!),
   `RATE_LIMIT_MAX=10` (POST `/api/extract` и `/api/candidates` — не больше
   10 запросов в минуту, иначе 429 с `Retry-After`).
4. `APP_TOKEN` — токен доступа рекрутёра к списку, правке и удалению кандидатов
   (запросы без токена получают 401; отправка резюме формой работает у всех).
   Генерация: `node -e "console.log(require('crypto').randomBytes(24).toString('base64url'))"`.
   Вход рекрутёра: нажмите кнопку **«Ввести токен»** рядом с бейджем и вставьте
   значение `APP_TOKEN` из `.env` — либо откройте
   `http://localhost:3000/?token=ВАШ_ТОКЕН` (токен запоминается на вкладке).

### Сертификаты

Для GigaChat нужен корневой сертификат НУЦ Минцифры — он скачан в
`certs/russian_trusted_root_ca_pem.crt` и подключается автоматически.
Путь можно переопределить переменной `GIGACHAT_CA_BUNDLE`.

## Вариант 3 — демо (без ключа и `.env`)

```bash
npm run demo    # http://localhost:3000/?token=demo-token
```

Сервер поднимается на вымышленных кандидатах из `demo/candidates.demo.json`
(список, поиск, правка, экспорт — сразу можно показывать). `.env` не нужен,
разбор идёт эвристикой, токен доступа — `demo-token`. Правки пишутся в
`demo/candidates.local.json` (в `.gitignore`): реальный `candidates.json`
не читается и не меняется, демо-база сбрасывается удалением этой копии.

## Хранение кандидатов

- **С сервером**: `GET/POST /api/candidates`, `PUT/DELETE /api/candidates/:id`,
  поиск `?q=` — всё в файле `candidates.json` (в Git не попадает: персональные
  данные). Плюс кнопки «Редактировать»/«Удалить» и экспорт JSON/CSV в UI.
- **Без сервера**: тот же интерфейс работает на `localStorage` браузера
  (кроме: поиск и экспорт — только по загруженным записям, данные общими
  базами не станут).

## Проверка

```bash
node --check src/server.js && node --check public/js/script.js   # синтаксис
npm test                                           # эвристика (79 проверок) + API (28 проверок на изолированном сервере)
curl http://localhost:3000/api/health               # {"ok":true,"ai":true,...}
```

## Файлы

- `public/` — фронтенд: `index.html`, `css/style.css`, `js/script.js`
  (клиент: карточка, вызов `/api/extract` с фолбэком), `js/heuristics.js`
  (эвристика), `presentation.html` (презентация, `/presentation`)
- `src/server.js` — Express: статика + `POST /api/extract` (GigaChat OAuth → chat)
  + CRUD кандидатов
- `src/demo.js` — демо-режим (`npm run demo`): копия демо-базы, токен `demo-token`
- `demo/` — `candidates.demo.json` (вымышленные кандидаты, в Git) и
  `candidates.local.json` (рабочая копия, в `.gitignore`)
- `certs/` — сертификат НУЦ Минцифры
- `tests/` — автотесты (`npm test`, `npm run test:ui`)
- `docs/` — документация, скриншоты, отчёт аудита
- `.env.example` — шаблон переменных окружения (заполняется вручную)
- `docs/PROMPT_EXAMPLE.md` — пример промпта
- `package.json` — зависимости (`express`, `dotenv`, `helmet`)
