# Памятка: работа с сервером «ПроКадры»

Команды вводятся в командной строке (Win+R → `cmd`).
Папка проекта: `C:\Users\User\Documents\Vibe_rf\Kadry_AI`

---

## 1. Запуск

```bash
cd C:\Users\User\Documents\Vibe_rf\Kadry_AI
npm start
```

Появится строка (держите это окно открытым):

```
Prokadry server: http://localhost:3000 (AI=on, cert=ok, model=GigaChat-2-Pro)
```

Страница: **http://localhost:3000**

## 2. Проверка — сервер работает?

Отдельная команда (в новом окне терминала):

```bash
curl http://localhost:3000/api/health
```

| Ответ | Значение |
|---|---|
| `{"ok":true,"ai":true,...}` | работает, ИИ подключён |
| `{"ok":true,"ai":false,...}` | работает, но не задан ключ в `.env` |
| ошибка соединения | сервер не запущен — выполните `npm start` |

Запасной вариант проверки:

```bash
netstat -ano | findstr :3000
```

Строка с `LISTENING` → сервер работает.

## 3. Остановка

- Если открыто окно с `npm start` → нажмите в нём **Ctrl+C**.
- Если окно закрыли, а сервер в фоне:

```bash
netstat -ano | findstr :3000
```

По столбцу справа найдите PID (например `8456`) и выполните:

```bash
taskkill /PID 8456 /F
```

## 4. Перезапуск (после правок кода)

```bash
taskkill /PID <номер из netstat> /F
npm start
```

## 5. Где хранятся данные

| Файл | Что это | В Git? |
|---|---|---|
| `candidates.json` | база кандидатов (персональные данные) | **нет** (не коммитить!) |
| `.env` | ключ GigaChat и настройки | **нет** (не коммитить!) |
| `certs/` | сертификат Минцифры для GigaChat | да |

**Резервная копия базы:** просто скопируйте `candidates.json` в безопасное место.
**Очистка базы:** остановите сервер, удалите `candidates.json`, запустите заново.

## 7. Безопасность — обязательно

- Ключ `GIGACHAT_AUTH_KEY` живёт **только** в `.env`; страница его не видит.
- Токен `APP_TOKEN` (в `.env`): список/правка/удаление кандидатов требуют
  заголовок `Authorization: Bearer <токен>`; без него — 401. Вход рекрутёра:
  кнопка «Ввести токен» рядом с бейджем или
  `http://localhost:3000/?token=ВАШ_ТОКЕН`. Отправка резюме формой работает без токена.
- Не отправляйте файл `.env` и `candidates.json` по почте/в мессенджерах.
- Перед коммитом проверьте: `git status` — этих файлов там быть не должно.

## 8. Частые проблемы

| Симптом | Решение |
|---|---|
| Страница не открывается | проверьте, запущен ли сервер (п. 2), порт 3000 |
| «Порт уже занят» | найдите PID через `netstat` и `taskkill` (п. 3), затем `npm start` |
| Не видно бейдж «Хранилище: …» | обновите страницу с **Ctrl+Shift+R** |
| Резюме не сохраняется | F12 → Console → пришлите текст ошибки |
| ИИ не отвечает, но форма работает | включён режим эвристики — проверьте `.env` и строки лога при запуске |
| Ошибка SSL / сертификат | файл `certs/russian_trusted_root_ca_pem.crt` на месте? |
