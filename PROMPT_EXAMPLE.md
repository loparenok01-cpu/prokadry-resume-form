# Пример промпта — извлечение данных из резюме

Если решите подключить настоящий ИИ вместо эвристики, вот ориентир для
запроса (например, к OpenAI Chat Completions API).

## Системный промпт

```
Ты — помощник рекрутёра. Из присланного текста резюме извлеки: имя
кандидата, ключевые навыки (кратко, через запятую), опыт работы
(кратко, например "5 лет в маркетинге") и контакты (телефон/email).
Верни строго JSON вида {"name": "...", "skills": "...",
"experience": "...", "contacts": "..."}. Если какое-то поле не
удалось найти — оставь пустую строку.
```

## Пользовательский промпт (подставляется текст резюме)

```
Текст резюме: "{{текст резюме}}"
```

## Ожидаемый ответ модели

JSON вида `{"name": "Мария Иванова", "skills": "SMM, аналитика",
"experience": "5 лет", "contacts": "+7 900 111-22-33"}` — используйте
поля как значение для карточки кандидата.
