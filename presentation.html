Кейс проекта

Форма приёма резюме «ПроКадры»

Сайт кадрового агентства: кандидат вставляет резюме текстом, сервис извлекает 7 полей (ИИ GigaChat с эвристическим фолбэком) и ведёт базу кандидатов на сервере — с поиском, редактированием и экспортом

Ссылка на GitHub — после публикации

Задача и контекст

Задача

Принимать резюме произвольного формата (headhunter, текст из письма, «стена» из разделов) и превращать их в структурированную карточку кандидата — без ручного переноса полей.

Целевая аудитория

Рекрутёры кадрового агентства, обрабатывающие поток резюме, и сами кандидаты, которые отправляют резюме через сайт.

Проблема

Резюме приходят сплошным текстом в десятках разных оформлений: зарплата прилипает к соседнему разделу, навыки прячутся под «Профессиональными качествами», контакты — в шапке. Ручной разбор долгий и с ошибками.

Решение

Решение

Одностраничное приложение: форма отправки → извлечение полей через GigaChat API с автоматическим фолбэком на эвристику → карточка кандидата в общей базе на Express-сервере.

Основные функции

7 полей: имя, желаемая должность, зарплата, навыки, опыт, образование, контакты. Добавление, редактирование и удаление; поиск по всей базе; экспорт в JSON и CSV; работа без ИИ (эвристика) и с ИИ (GigaChat).

Использованные инструменты

Node.js и Express; GigaChat API (OAuth + chat completions, сертификаты НУЦ Минцифры); эвристический парсер на чистом JavaScript; хранилище candidates.json; автотесты (75 эвристика + 14 API); OpenCode для разработки.

Результат

Рабочий сервис по техническому заданию: кандидат отправляет резюме — рекрутёр через секунду видит структурированную карточку и правит её прямо на странице. База хранится на сервере и доступна всем, кто открыл сайт; при недоступном ИИ форма продолжает работать на эвристике. Автоприёмка: 75 + 14 проверок.
