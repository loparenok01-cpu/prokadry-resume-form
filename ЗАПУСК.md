# Запуск стартового проекта

Форма приёма резюме кадрового агентства — без сервера и без сборки.

## Как запустить

Откройте `index.html` двойным щелчком (или File → Open в браузере).
Если браузер ругается на `localStorage` при открытии файла напрямую
(`file://`), запустите локальный сервер:

```bash
python3 -m http.server 8000
```

## Что нужно сделать

Базовая функциональность уже работает: форма сохраняет резюме целиком
как есть, список сохраняется в `localStorage`. Ваша задача — добавить
**одну** ИИ-функцию: извлечение из текста резюме структурированных
данных — имя, ключевые навыки, опыт работы, контакты — и показ их
отдельной карточкой.

Место для реализации отмечено комментарием `// TODO:` в `script.js`,
функция `extractStructuredData(text)` — сейчас всегда возвращает
пустые значения, замените на реальное извлечение.

Два допустимых уровня реализации:

1. **Простая эвристика** — без реального ИИ: поиск по ключевым словам
   и шаблонам в тексте (например строка с «Телефон:»/«+7» → контакты,
   строка с «Навыки:» → навыки, число + «лет опыта» → опыт). Работает
   надёжно, только если резюме в тестовых примерах написаны в похожем
   формате — это нормально для тренировочного задания.
2. **Вызов внешнего ИИ-API** — ориентир по переменным окружения — в
   `.env.example`, пример запроса — в `PROMPT_EXAMPLE.md`. Этот вариант
   надёжнее работает с произвольным текстом резюме.

Структурированные данные показываются карточкой под исходным текстом
(стиль `.candidate-structured` уже готов в `style.css`).

Файлы:

- `index.html` — разметка экрана
- `style.css` — стили
- `script.js` — логика; функция `extractStructuredData` — то, что нужно реализовать
- `.env.example` — переменные окружения для варианта с внешним API
- `PROMPT_EXAMPLE.md` — пример промпта для варианта с внешним API
